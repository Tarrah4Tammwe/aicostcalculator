How to read the number

The figure is a list-price estimate for text tokens. It multiplies your monthly requests by the tokens in each request, splits input between full price and the cache-read price, then adds output. A support chatbot at 50,000 requests, 800 input tokens, and 250 output tokens is 40 million input tokens and 12.5 million output tokens. On GPT-6 Sol's short-context rate that is $80 of input and $125 of output, or $205 a month before any cache hits.

Output is usually the expensive side. Sol charges $10 to generate a million tokens and $2 to read a million. If a coding agent writes long patches, cutting output length changes the bill more than swapping a mid-tier model for another mid-tier model.

What the toggles change

Cache is the share of input tokens served from a stored prefix. Cache reads are cheaper. The first time a prefix is written, providers bill a separate cache-write fee that this estimate leaves out, because it depends on how often the prefix changes.

Batch applies a published 50% discount for OpenAI, Anthropic, and Google. xAI does not publish a batch discount, so those rows stay on the standard rate. DeepSeek uses peak and off-peak hours instead. The calculator prices DeepSeek at the peak rate, and off-peak is half of that.

Long context matters when a provider reprices the whole request past a threshold. OpenAI does that above 272,000 input tokens. Gemini 3.1 Pro and the Grok models do it at 200,000. Claude's current models on this card keep one rate across the window.

Questions

How much does the GPT-6 Sol API cost?

On the standard short-context tier, GPT-6 Sol is $2 per million input tokens, $0.20 per million cached input tokens, and $10 per million output tokens. Prompts over 272,000 input tokens are billed at $4, $0.40, and $15 for the whole request. Batch is half of whichever tier you are on. Checked 26 September 2026 on OpenAI's pricing page.

Which API on this card has the lowest list price?

GPT-6 Luna: $0.10 per million input tokens and $0.50 per million output tokens, with cached input at $0.01. Gemini 3.1 Flash-Lite is $0.25 and $1.50. DeepSeek V4.1 Flash peaks at $0.30 and $1.20, and off-peak is half of that, which is still above Luna on both input and output.

How do you calculate a monthly bill by hand?

Divide fresh input tokens by one million and multiply by the input rate. Do the same for cached input at the cache-read rate, and for output at the output rate. Add the three. The guide walks through a full example, and the methodology writes the formula without the interface around it.

Does this page store what I type?

The estimate runs in your browser. The page puts the workload in the address bar so a link can be bookmarked or shared. Those figures describe a volume of tokens, not a person. There is no account. Details are in the privacy policy.

Why can the invoice be higher?

List price for text tokens is the floor of a bill, not the ceiling. Cache writes, tool calls, images, audio, data-residency surcharges, retries, and failed requests sit outside this estimate. On Gemini, thinking tokens are billed as output, so they belong in the output number you enter.
