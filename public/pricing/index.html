The rate card behind the calculator.

Every figure is US dollars per million tokens on the provider's standard text tier. "Cached" means a cache read, not a cache write. Batch, where a provider publishes it, is half of the row. Use the calculator when you want those rates applied to a monthly volume.

How to read a row

Input is uncached text. Cached is a later read of a prefix the provider already stored. Output is generated text. On Gemini, the published output price includes thinking tokens, so a short visible answer can still be a long billed output.

OpenAI's batch and flex tiers are half of standard, including the long-context column. Anthropic's batch API is half of the base token price. Google's batch tier on the three Gemini rows is half of standard. xAI's pricing page does not list a batch price for Grok 4.3, Grok 4.6, or Grok Build 0.1.

DeepSeek's peak hours are 01:00–04:00 and 06:00–10:00 UTC, Monday through Friday, excluding Chinese public holidays. Every other hour, including weekends, is off-peak at half the peak rate. The table shows peak, which is the higher bill.

Where each rate comes from

  • OpenAI API pricing for GPT-6 Luna, Sol, and Astra, including cached input, cache writes, batch, and the long-context column.
  • Claude Opus 5.5 for the $4 / $0.20 / $20 rates and the $5 cache-write price.
  • Claude Sonnet 5 for the permanent $2 / $10 price.
  • Anthropic models overview for Haiku 4.5 at $1 / $5, Fable 5.1 at $10 / $50, the 50% batch discount, and cache reads at 10% of input (2.5% on Fable 5.1).
  • Gemini API pricing for Gemini 3.5 Flash, 3.1 Flash-Lite, and 3.1 Pro, including batch and context caching.
  • xAI API pricing for Grok 4.6, Grok 4.3, and Grok Build 0.1 under and over 200K prompt tokens.
  • DeepSeek API pricing for deepseek-flash (V4.1) and deepseek-v4-pro, peak and off-peak.

Claude Opus 5 is still listed by Anthropic at $5 input and $25 output. Opus 5.5 replaced it as the current Opus price, so the older row is not in the calculator. GPT-4o, GPT-4.1, and the April 2026 card this site used to show are retired from the estimator for the same reason.

A useful way to compare

Input prices cluster. GPT-6 Sol, Claude Sonnet 5, Gemini 3.1 Pro, and Grok 4.6 all sit at $2 per million input tokens on the short-context tier. Output is where they split: Grok 4.6 at $6, Sol and Sonnet at $10, Gemini 3.1 Pro at $12. A workload that writes a lot of text should be ranked on output, then checked again once cache hits are real. The pricing guide shows that split with one worked example.
